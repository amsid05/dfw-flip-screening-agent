# DFW Flip Screening Agent

A portfolio demo that screens hypothetical properties for a possible renovation and resale. All supplied addresses, listings, sales, and prices are **fictional**. It does not fetch live listings, estimate real property values, or make purchase decisions.

## What it does

1. Reads property and sold-comparable CSV files.
2. Filters sold comps by city, bedrooms, sale date (last 180 days), and size (within 20%). Prefers same ZIP when at least three exist. A row marked `SOLD` without a verified `sold_price` is excluded and reported; `last_list_price` is never used as the closing price. Vacant land is `OUT_OF_SCOPE`.
3. Estimates after-repair value (ARV) from median sold dollars per square foot. Requires three comps; otherwise returns `NEEDS_DATA`.
4. Calculates rehab plus contingency, purchase closing, selling, financing, taxes, insurance, HOA, utilities, estimated profit, cash invested, ROI, a 10% resale downside, and a maximum offer for a **minimum dollar profit**. The max-offer figure does not enforce the ROI target.
5. Classifies `REVIEW`, `PASS_AT_ASK`, `DUE_DILIGENCE`, or `NEEDS_DATA` using editable assumptions.
6. With `--ai`, a tool-using OpenAI agent asks for the computed results and drafts a triage memo. Python remains the source of truth for arithmetic.

## Run on Windows PowerShell

In the extracted project folder:

```powershell
python .\flip_agent.py --as-of 2026-09-26
```

The deterministic calculation needs no API or installed packages. It writes `flip_results.json`.

For the optional AI analyst, set `OPENAI_API_KEY` in your local environment (never paste it into source or GitHub), then:

```powershell
python -m pip install -r requirements.txt
python .\flip_agent.py --as-of 2026-09-26 --ai
```

This makes a billable API call. The model name in `flip_agent.py` can be changed to one available to your API account.

## Replace demo data

Add properties you are authorized to analyze to `sample_properties.csv` or pass `--properties your_properties.csv`. `property_type` must be `single_family` for this calculator. Add **verified sold transactions** to `sample_sold_comps.csv` or pass `--sales your_sold_comps.csv`. Set `status=SOLD`; put the last asking price in `last_list_price`, and put an independently verified closing price in `sold_price`. Leave `sold_price` empty if it is unavailable. Supply dates in `YYYY-MM-DD`. Use `--as-of` for a reproducible analysis date; otherwise it uses today's date. Adjust `assumptions.json` for the specific financing and deal. Prices and renovation figures must be estimates from identifiable sources, not values generated by the model.

Comp matching is deliberately simple; it does not adjust for renovation quality, location within ZIP, lot, layout, age, condition, concessions, or non-arm's-length sales. Ask a qualified local professional to validate comparable sales and value. Get contractor bids and inspections, title, insurance and tax figures, permits, HOA restrictions, and actual lender terms before making an offer. A screening status is **not** investment advice or an appraisal.

## Future improvements

- Licensed listing and sold-comp feed with provenance, timestamps, deduplication and refresh schedule.
- Photos and inspection notes routed to a human for renovation scope and separate contractor bids.
- Scenarios for hold-time overruns, rehab overruns and resale reductions; show break-even sale price.
- Map parcel-level tax districts, flood and insurance risks, HOA rules, permit history and days on market.
- Review queue with explicit approval before contacting agents or making offers; track predicted versus realized costs.
